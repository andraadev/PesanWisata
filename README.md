# PesanWisata App UI

## Cara menjalankan aplikasi ini di komputer anda:

Clone projek ini dengan menggunakan Terminal

```bash
  git clone https://github.com/andraadev/pesanwisata-reactjs.git
```

Setelah di clone, masuk ke dalam folder

```bash
  cd pesanwisata-reactjs
```

Install library yang diperlukan

```bash
  npm install
```

Jalankan Servernya
```bash
  npm start
```

Selesai.
